Estuary

Route, mix and clean up your audio on Linux. This is the Flatpak repository of Estuary.

Install Estuary: opens in GNOME Software, Pop!_Shop or KDE Discover. Updates arrive with your other apps.

Or from a terminal:

flatpak remote-add --user --if-not-exists estuary https://abidibo.github.io/Estuary/estuary.flatpakrepo
flatpak install --user estuary io.github.abidibo.Estuary

The GNOME runtime is installed from Flathub. See the README for requirements and a quick start.
